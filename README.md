# ☁️ Cloud Quiz

A responsive web-based quiz platform with **Student** and **Admin** roles. The application allows students to take quizzes and view their performance history, while administrators can manage quiz questions through a dedicated dashboard.

---

## 📌 Features

👨‍🎓 Student
- User Registration (Sign Up)
- Secure Login
- Attempt quiz tests
- View score immediately after submitting the quiz
- Dashboard showing the history of all previously attempted quizzes
- Track quiz performance over time

👨‍💼 Admin

- Secure Admin Login
- Add new quiz questions
- Delete existing quiz questions
- Dashboard displaying all questions stored in the database
- Manage quiz content efficiently

## 🚀 How It Works

### Student Workflow

1. Create a new account using the Sign Up page.
2. Log in as a Student.
3. Start the quiz.
4. Submit the quiz after answering all questions.
5. View the quiz result instantly.
6. Access the dashboard to see all previous quiz attempts and scores.

### Admin Workflow

1. Log in using Admin credentials.
2. Open the Admin Dashboard.
3. Add new quiz questions.
4. Delete existing questions.
5. View all available questions stored in the database.
